# Robotics Research

This repository contains research-related documentation for robotics work. It currently includes a Word document archive; it is not an executable robotics software package.

## Published Research

### Hybrid Random Walk-Dijkstra Approach for Efficient Coverage Path Planning in Robotics

**Publication:** Conference paper in *Intelligent Systems, Blockchain, and Communication Technologies*  
**Conference:** ISBCom 2025  
**First published online:** 1 April 2026  
**Pages:** 381–396  
**Publisher:** Springer Nature, Lecture Notes in Networks and Systems

**Authors:** Mohamed Badr, Abdelrahman Bedeir, Ramadan Mohamed, Nada Mohamed, Mariam Saad, Mariam Tharwat, Nesma Abdelgawad, Khaled Fouad, and Ibrahim Attiya.

**Summary:** The paper presents a hybrid coverage-path-planning approach combining the exploratory behavior of Random Walk with Dijkstra-based shortest-path planning between generated waypoints. The publisher's abstract describes simulation-based comparisons with standard Random Walk and Dijkstra approaches in environments containing obstacles.
